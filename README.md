# MakeMyCut

MakeMyCut is a modern salon and haircut booking platform built to eliminate waiting time through instant appointment scheduling and QR verification.

## Features

- Google Authentication
- Email OTP Login
- Salon Dashboard
- Instant Booking System
- QR Booking Verification
- Responsive UI
- Analytics Dashboard

## Tech Stack

- React
- TypeScript
- TailwindCSS
- Supabase
- Vercel

## Vision

Skip the wait. Book instantly.
